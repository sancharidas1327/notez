# Notezy

Notezy is a student-focused notes sharing platform designed to make learning more collaborative, accessible, and rewarding. The platform allows students to upload, discover, and access study materials through a gamified credit-based system with future AI-powered learning tools.

---

## Features

- Upload and share study notes
- Gamified credit/reward system
- Offline-first support
- Community-driven learning
- Modern responsive UI
- AI-powered roadmap features
- Smart content organization

---

## Installation

### Clone the repository

```bash
git clone https://github.com/sancharidas1327/notez.git
```

### Install dependencies

Frontend:

```bash
cd notez-frontend
npm install
```

Backend:

```bash
cd notez-backend
npm install
```

### Run the project

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```
